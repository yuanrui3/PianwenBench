# Contributing

Contributions are welcome: new items, drafts, judge-validation anchors, checkers and analysis.

## Sign-off

Every commit must carry a Developer Certificate of Origin sign-off
(<https://developercertificate.org/>), which `git commit -s` adds:

```
Signed-off-by: Your Name <you@example.com>
```

By signing off, you confirm that you wrote the contribution or have the right
to submit it, and that it may be distributed under this repository's licences:
Apache-2.0 for code and CC BY 4.0 for data and documents.

## Test items

- Never commit test-split items. Send them privately to the maintainer.
- Every data file must carry the canary line from `README.md`.
- Don't add copyrighted modern texts. Classical texts must be in the public domain.

## Authorship

Who counts as an author of a release is recorded in `AUTHORS.md`. Substantial
contributions of items, checkers or analysis qualify; small fixes are thanked
in the release notes.
